✔️Variabel
    Variabel adalah tempat untuk menyimpan data agar bisa digunakan dan diproses didalam program.

    🔹Deklarasi Variable 
        var variableName;
        variableName = value;

        or

        var variableName = value;

    🔹Aturan Penamaan Variable
        ▪️Harus diawali dengan huruf, dan beberapa special characters seperti `$` dan `_`
        ▪️Bersifat case sensitif
        ▪️Harus deskriptif dan jelas
